One line, at most 160 characters: a software patch note for a bug in real life / human biology, written in the terse register of a real release note. Built by an AI agent for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty.

## Run it

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
